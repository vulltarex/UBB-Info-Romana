# SDA: Structuri de date și algoritmi

Anul I, semestrul 2 · **C++**

Fiecare laborator implementează un tip abstract de date (TAD) cu iteratorul lui. Se verifică cu testele primite (`TestScurt`, `TestExtins`).

## Conținut

| Folder | TAD |
|---|---|
| `Laborator/L1` | Mulțime - vector dinamic |
| `Laborator/L3` | Listă ordonată (LO) - lista inlantuita cu alocare dinamica |
| `Laborator/L4` | Dicționar ordonat (DO) - lista inlantuita pe tablou |
| `Laborator/L6` | Dicționar - tabela de dispersie |
| `Laborator/L7` | Colecție - arbore binar de cautare |

## Examen

Folderul `Examen/` continte multe modele de subiecte din care se pot identifica si exersa tiparele de exercitii de la fiecare punct
